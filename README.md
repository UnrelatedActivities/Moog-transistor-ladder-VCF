Moog style transistor ladder VCF with Voltage Controlled resonance and output VCA.

Version 1c features a better amplifier circuit converting the LM13600 OTA VCA
output current into the final voltage signal.

The VCF is based on ASM2 VCF2 and Moog Sub-Phatty VCF circuits.
PCB is untested, but should not contain errors. This version does not include a pole selector, 
like the one found in the Moog Sub Phatty, just voltage controlled resonance and the output VCA. 
It was designed as a single side PCB for homade DIY, you should check for compatibility with PCB 
manufacturers if you want to use their services. 
More information at www.youtube.com/@unrelatedactivities
